# Personel Kayıt ve Stok Takip Sistemi

## Proje Açıklaması

Bu proje, C# Windows Forms kullanılarak geliştirilmiş bir personel kayıt ve stok takip sistemidir.

Uygulama içerisinde kullanıcılar kayıt olup giriş yapabilir, personel ve stok bilgilerini yönetebilir.

Veri saklama işlemleri SQL Server veritabanı üzerinden gerçekleştirilmektedir.

---

## Özellikler

* Kullanıcı kayıt ve giriş sistemi
* SQL Server veritabanı bağlantısı
* Personel ekleme, silme ve güncelleme
* Stok ekleme, silme ve güncelleme
* DataGridView ile veri listeleme
* Temel CRUD işlemleri

---

## Kullanılan Teknolojiler

* C#
* Windows Forms
* SQL Server
* DataGridView
* SQL bağlantı işlemleri

---

## Proje Amacı

Bu proje, Windows Forms ve veritabanı mantığını öğrenmek, veri yönetimi ve kullanıcı işlemleri üzerinde pratik yapmak amacıyla geliştirilmiştir.
